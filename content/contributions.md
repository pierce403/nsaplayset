## What makes a useful contribution?

A working design is only part of the story. Help another researcher understand the capability, find the source, and reproduce the result.

Include a short overview, author credits, source and license information, hardware or software requirements, instructions, and a clear statement of what has actually been tested. Keep observed results separate from proposed features.

## Correct an existing record

Useful corrections include original URLs, missing presentations, credited contributors, repository moves, and dated compatibility reports. Include a source that others can inspect.

The catalog is maintained as Markdown in [pierce403/nsaplayset](https://github.com/pierce403/nsaplayset). [Open an issue](https://github.com/pierce403/nsaplayset/issues/new) with a correction or submit a pull request to contribute a project. The [original discussion group](https://groups.google.com/g/nsaplayset) is retained as a historical reference; its current activity has not been verified.

## Before submitting

Read the [project requirements](/project-requirements/) and the [archive notes](/archive/). Preserve upstream attribution and identify the license for files you contribute.
